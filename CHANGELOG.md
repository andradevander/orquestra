# Changelog

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [SemVer](https://semver.org/).

## [0.1.0] - 2026-11-18

### Added
- Spec-driven workflow: `init`, `specify`, `clarify`, `plan`, `implement`, `review`, `drift`.
- Lean `quick` path for changes of up to ~5 files.
- Versioned project memory: `note`, `recall`, `consolidate`.
- `orchestrate` skill (the supervisor's playbook) with brief templates and a token economy guide.
- `responsive-ui` skill with patterns, pitfalls, orchestration, and the `desktop_guard.py` verifier.
- Agents: `scout` (Haiku), `implementer`, `tester`, `goldfish-reviewer`, `goldfish-reader`, `responsive-auditor` (Sonnet).
- Documentation: getting started, workflows, memory, theory, extending, and troubleshooting.
